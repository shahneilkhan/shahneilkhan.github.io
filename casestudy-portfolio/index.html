Case Study

Building the SNK Ecosystem

Problem

As a self-taught engineer and designer with no formal degree, I needed a portfolio that could do more than list skills — it needed to prove them. I also wanted to showcase multiple ventures (WebsitesDeal, Tabayyun TV, and more) under one connected identity, without any budget for premium tools or hosting.

Approach

I built the entire ecosystem iteratively — one section, one page, one improvement at a time — using only free tools: HTML, CSS, and JavaScript, hosted on GitHub Pages. Each sub-brand (WebsitesDeal, SNK IT Institute, Sarakāt Agency, SNK Design, Tabayyun TV) was designed as its own connected site, sharing a consistent premium dark aesthetic while keeping its own identity.

Tools

GitHub Pages for free hosting, vanilla HTML/CSS/JS for full control with zero dependencies, Figma and Photoshop for visual design — no paid services anywhere in the stack.

Result

A fully live, multi-site ecosystem — a personal portfolio connected to real, working sub-brands — built entirely self-taught, at zero cost. The build process itself became the strongest proof of the skills the portfolio claims.
